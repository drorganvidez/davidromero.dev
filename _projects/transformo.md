**[Transformo](https://github.com/diverso-lab/transformo)** es un framework para
migrar entre bases de datos relacionales usando líneas de producto software: en
vez de escribir cada migración a mano, se configura y se obtienen scripts SQL a
medida y compatibles entre sí.
